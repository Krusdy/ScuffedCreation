## 🎵 SpotifyPlaylistFetcher.py
**SpotifyPlaylistFetcher.py** is a simple tool to extract Spotify playlist data and save it into a `.txt` file.
### **Features**
* Extract all **public playlists of a user**, including:
  * Playlist **name**
  * Playlist **description**
  * Playlist **link**
* Extract details from a **specific playlist**, including:
  * Playlist **name**, **description**, and **link**
  * All **songs** with their **title** and **artist name**
### **How to Use**
1. Download and run **SpotifyPlaylistFetcher.py**.
2. Paste a Spotify **user** or **playlist** URL — it will open a website.
3. Copy the website address and paste it **once** into the CMD window.
4. A `.cache` file will be created in the same folder as **SpotifyPlaylistFetcher.py**.
5. As long as the `.cache` file exists, you don’t need to paste the address again.
6. The extracted data will be saved into a `.txt` file in the same folder.
