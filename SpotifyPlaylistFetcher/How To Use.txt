SpotifyPlaylistFetcher — Usage Guide

This tool extracts Spotify data and saves it into .txt files.

Features
- User link: exports Overview and Full playlists files
- Playlist link: exports playlist metadata and all tracks
- Artist link: exports artist metadata and releases

Setup
1) Create a folder
2) Put SpotifyPlaylistFetcher.py inside
3) Create a folder named "libs" next to it
4) In VS Code terminal, run:
   python -m pip install spotipy -t libs

Usage
1) Run:
   python SpotifyPlaylistFetcher.py
2) Paste any Spotify user / playlist / artist link
3) A browser will open → approve
4) Copy the final redirected URL and paste it back into terminal
5) Exported files are stored in "exports" folder

Cache
.cache is created after first authorization.
It saves your Spotify token so future runs don’t require browser login, unless token expires.

Warning
This tool can only access PUBLIC playlists.  
Private or hidden playlists will not be included.
