SpotifyPlaylistFetcher — Usage Guide

Overview
This tool exports Spotify data into .txt files for easy reference.

Features
- User link: Overview, Full Details, Full Details Links, All Tracks Links
- Playlist link: Playlist Info, Playlist Links
- Artist link: Albums Overview, Full Details, Full Details Links, All Tracks Links

Setup
1) Place SpotifyPlaylistFetcher.py in a folder
2) Open VS Code
3) Open terminal (default shortcut: Ctrl + `)
4) Run:
   python -m pip install spotipy
5) Open spotify_keys.txt
6) Replace CLIENT_ID and CLIENT_SECRET with your own values from https://developer.spotify.com/dashboard

Usage
1) Run:
   python SpotifyPlaylistFetcher.py
2) Paste any Spotify user, playlist, or artist link
3) Approve authorization in the browser if prompted
4) Copy the redirected URL and paste it back into the terminal
5) All exported files are stored in the "exports" folder

Cache
A .cache file is created after first authorization.
It stores your Spotify token so future runs do not require browser login unless the token expires.

Notes
- Only PUBLIC playlists and albums are accessible
- Private or hidden playlists will not be included
