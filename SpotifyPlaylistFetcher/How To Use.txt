Overview
This tool exports Spotify data into .txt files for easy viewing and reference. It supports exporting all playlists of a user, a single playlist, other users’ playlists, or artist data.

Features
User link
- Overview
- Full details
- Full details with links
- All track links

Playlist link
- Playlist information
- Playlist links
- Track links sorted Newest → Oldest
- Track links sorted Oldest → Newest

Artist link
- Album overview
- Full details
- Full details with links
- All track links

Setup
1) Place SpotifyPlaylistFetcher.py in any folder
2) Open the folder using Visual Studio Code
3) Open the terminal (Ctrl + `)
4) Run the following command (one time only):
   python -m pip install spotipy
5) Open spotify_keys.txt
6) Replace CLIENT_ID and CLIENT_SECRET with your own keys from https://developer.spotify.com/dashboard

- Using your own CLIENT_ID and CLIENT_SECRET allows you to fetch all playlists your account can see
- Using someone else’s CLIENT_ID and CLIENT_SECRET limits access to playlists that account can see

Usage
1) Run SpotifyPlaylistFetcher.py by double-clicking it in the folder
2) Paste a Spotify user, playlist, or artist link into the command prompt
   (copy the link, right-click in the command prompt, then press Enter)
3) If the .cache file does not exist, the program will open a browser for one-time authorization:
   - Approve access
   - Copy the full URL from the browser
   - Paste it back into the command prompt and press Enter
4) All exported files are saved in the exports folder

Cache
The .cache file stores your Spotify token after the first authorization, so you do not need to authorize again or paste the URL on future runs.

Notes
- Only PUBLIC playlists that are added to a profile can be accessed
- Private or hidden playlists are not included
